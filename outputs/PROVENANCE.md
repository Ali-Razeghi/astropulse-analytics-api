# Output provenance

- DONKI records are real records reproduced from NASA CCMC DONKI API documentation.
- The Exoplanet Archive total is the public archive statistic reported for 2026-06-04; representative planet records are established catalog objects.
- The NeoWs image demonstrates the application's normalized response for NASA's official documented example request. The execution environment used to package this repository could not make outbound API calls, so it is marked as a representative normalized snapshot rather than a newly downloaded live response.
- Running AstroPulse with network access fetches live provider data.
